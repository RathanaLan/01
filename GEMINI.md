# Agent Instructions & Memory Rules

## Autonomous Execution & Permission Policy
- **Never Ask for Permission**: The user grants full permission for all tasks, file edits, command executions, installations, and system operations. Never pause or ask "would you like me to proceed?" or ask for permission. Proceed autonomously and proactively.
- **Always Provide Confirmation Before Finishing**: Always perform thorough automated verification first, and provide a clear confirmation and summary of the completed work, changes made, and test results before concluding.
- **Zero Follow-up Questions**: Do not end turns with questions or open-ended inquiries ("Would you like me to...?", "Let me know if you want..."). Complete tasks definitively.
