🛠️ 3-Tier Troubleshooting Audit

Tier A (App): Check if row exists in SharePoint. If yes, Power Apps is 100% innocent!
Tier B (Flow Trigger): Check Power Automate 28-day Run History. If 0 runs, check credentials or list name.
Tier C (Action Delivery): Inspect the run's email card. If red ✕, bad address; if green ✓, check Spam.
