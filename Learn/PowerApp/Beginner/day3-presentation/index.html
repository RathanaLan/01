Workplace Case Study

Apex Plastics: The $24,000 Text-Math Disaster

How a single misconfigured field crippled production and delivered 1,020 pallets instead of 30.

⚠

INCIDENT REPORT: Resin Pellet Reorder Catastrophe

Apex Plastics Injection Molding Facility • Plant #3 Dock B

What the Human Intended:

Shift 1 Request: 10 Pallets Shift 2 Request: 20 Pallets
Expected Order: 30 Pallets ($6,000)

What the Computer Executed (Text Concatenation):

Field Type: Text (String) Operation: "10" & "20"
Delivered: 1,020 Pallets ($204,000)
Root Cause: The app creator used a generic Text input without enforcing a Number data type. To a computer, "Cat" + "Dog" = "CatDog", and "10" + "20" = "1020"!

Golden Rule of Data Modeling

When is a Number NOT a Number?

Just because a value contains digits does NOT make it a mathematical Number.

🏆

The Golden Test: "Will you ever calculate with it?"

If you will never add, subtract, multiply, or average the value, it belongs in a Text container!

❌ Dangers of Storing as a Number:

  • Loss of Leading Zeros: Boston ZIP "02138" becomes 2138.
  • Stripping Formatting: Phone "+855-23-888" throws a math error!
  • Serial Numbers: Part ID "007-B" crashes if forced to numeric.

✔ True Numbers vs. Text Digits:

  • True Numbers: Hourly Rate ($25.50), Scrap Quantity (14), Downtime Hours (2.5).
  • Text Digits: Phone Number, National ID, Badge Number, Postal Code, Serial Tag.

Data Conversion Bridges

Converting Data: The Value() & Text() Bridges

Moving safely between text strings, mathematical numbers, and calendar dates.

Text ➞ Number

The Value() Function

Extracts numeric digits from a text string so you can perform safe arithmetic.

Value("45.5") + Value("10") = 55.5
⚠ If the text contains letters like "abc", Value() returns Blank/Error.
Number / Date ➞ Text

The Text() Function

Formats numbers or dates into human-readable text strings for labels and emails.

Text(Today(), "dd-mmm-yyyy") = "29-Oct-2026"
Text(5420, "$#,###") = "$5,420"
✔ Perfect for clean executive reports and UI feedback.

Mental Model Corrections

4 Common Beginner Misconceptions & Trainer Fixes

Correcting plausible but dangerous wrong mental models before they become bad habits.

❌ Wrong Mental Model #1

"If it has digits, it must be a Number."

Trainer Correction: Phone numbers, employee badge IDs, and postal codes are Text. True numbers are reserved exclusively for mathematical quantities.

❌ Wrong Mental Model #2

"Yes/No is just typing the words 'Yes' or 'No'."

Trainer Correction: Yes/No is a binary Boolean state: true or false. Storing it as text wastes storage and breaks conditional logic.

❌ Wrong Mental Model #3

"The app will guess what I mean and do math."

Trainer Correction: Computers never guess. A text box outputs "10". To add it, you must use Value(TextInput.Text) or configure the control as Numeric.

❌ Wrong Mental Model #4

"I can just store dates as simple text words."

Trainer Correction: Storing "29-Oct-2026" as text means the computer cannot calculate expiration dates, check past-due status, or sort chronologically.
