Part 6 • Layer 5 Transfer

Layer 5: Power Fx Decision Rules & Gatekeeper Logic

Enforcing business rules through Boolean questions, conditional formatting, and lifecycle hooks.

🔒 Gatekeeper Submit Validation

// btnSubmitHazard.DisplayMode
If(
  IsBlank(cmbLocation.Selected.Value) Or IsBlank(txtDescription.Text),
  DisplayMode.Disabled,
  DisplayMode.Edit
)

Why it works: The Or operator evaluates to True if either required field is empty, locking the button in gray to prevent corrupted database records.

🎨 Severity Badge Conditional Color

// lblSeverityBadge.Fill
Switch(
  ThisItem.Severity.Value,
  "Critical", RGBA(239, 68, 68, 0.8),
  "High", RGBA(245, 158, 11, 0.8),
  RGBA(16, 185, 129, 0.8)
)

Why it works: Switch() evaluates the hazard severity choice and applies instant visual triage colors so critical hazards scream for attention.

Trainer Speaking Script & Pedagogical Cues:

Logic Explanation (3 min): "Ask the learner: 'What is the question being asked in the submit button?' The question is: Is the location empty, or is the description empty? If yes, disable the button. Plain English first!"

Part 6 • Layers 8 & 9 Transfer

Layers 8 & 9: The 3-Tier Systematic Troubleshooting Framework

When someone reports an error, never guess or rewrite working code. Execute the 3-Tier Audit.

Tier A • Power Apps Layer

Did the Record Land in SharePoint?

Open SharePoint list in browser. Look for the newly reported hazard.

✕ Row Missing: Power Apps failed to submit. Check Form.Error, Wi-Fi, or validation rules.
✓ Row Exists: Power Apps is 100% innocent! NEVER touch app code! Move to Tier B.
Tier B • Flow Trigger Layer

Did Power Automate Wake Up?

Open Power Automate → Flow Details → Inspect Run History.

✕ No Runs Listed: Trigger failed to detect item. Check if Flow is turned On or credentials expired.
✓ Run Listed: Trigger successfully fired! Move to Tier C to inspect the action card.
Tier C • Email Delivery Layer

Did the Email Action Succeed?

Click inside the Run History to inspect the Send an email (V2) card.

✕ Red ✕ on Card: Action failed. Recipient address had a typo or permissions were denied.
✓ Green Checkmark: Email was dispatched! Check recipient's Junk / Spam folder in Outlook.

Trainer Speaking Script & Pedagogical Cues:

Diagnostic Discipline (3 min): "Drill this into the student: 'If the row exists in SharePoint, do you touch your Power Apps code?' NEVER! Doing so only breaks working software. Move calmly to Tier B."
