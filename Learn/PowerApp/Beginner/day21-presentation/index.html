Part 3 • Deep UI Anatomy

Anatomy of the Template Cell: One Blueprint Stamped 100 Times

Why you never edit the second or third row in a Power Apps Gallery.

The Master Row

How the Template Cell Governs the Entire List

When you select a Gallery on the canvas, look at the very top row. You will see a small pencil icon (Edit gallery) and a distinctive selection boundary.

The Golden Rule of Template Editing:

Any control placed inside the first cell automatically duplicates into EVERY row below it! You cannot select row 2 or row 3 to drag controls into them directly.

If you resize the template height by pulling the bottom handle down 20 pixels, every row in the gallery grows by 20 pixels in unison.

Visual Indicators

What Belongs Inside vs. Outside

✓
Inside the Template:

Labels, badges, status icons, chevron arrows, and thumbnail images that change per record.

✗
Outside the Gallery:

Screen headers, search bars, sort dropdowns, and master submit buttons that belong to the screen as a whole.

Part 4 • Power Fx Deep Dive

Deciphering ThisItem: Row Scope vs. Table Arrays

Why writing the table name inside a gallery fails, and why ThisItem always succeeds.

The Beginner Syntax Trap

Writing Apex_Maintenance_Requests.Title

A beginner thinks: "Title is in the table, so I'll write Apex_Maintenance_Requests.Title inside the label."

✗ Label.Text = Apex_Maintenance_Requests.Title
// Error: Expected text, got a Table/Array!

Why it fails: The table name refers to ALL 150 rows at once! A single Label cannot display 150 titles simultaneously; it doesn't know which row it belongs to.

The Correct Solution

Writing ThisItem.Title

The keyword ThisItem tells Power Fx: "Give me the Title of the specific record being stamped right now!"

✓ Label.Text = ThisItem.Title
// In Row 1 -> "Machine M-04 Overheating"
// In Row 2 -> "Conveyor C-02 Belt Slipping"

Why it succeeds: ThisItem establishes contextual row scope. The same exact formula works dynamically across every row in the dataset!

Trainer Speaking Script & Pedagogical Cues:

Analogy: "If you walk into a classroom of 30 students and say 'Person's name!', everyone gets confused. If you point to one student and say 'THIS person's name', you get a clear answer!"

Part 4 • Field Formatting Rules

Formatting Columns Inside the Template: Text, Date & Choice

Applying the correct Power Fx syntax for different SharePoint data types.

Single Line of Text

Title & MachineID

Simple text fields require no conversion. Directly access the string value:

ThisItem.Title
ThisItem.MachineID
✓ Native text string
Date & Time Field

LoggedDate

Cloud dates look messy without formatting (e.g. 2026-10-31T07:15). Wrap in Text():

Text(ThisItem.LoggedDate, "dd-mmm-yyyy")
✓ Outputs: 31-Oct-2026
SharePoint Choice Field

Priority & Status

Choice fields return a record object. You MUST append .Value:

ThisItem.Priority.Value
ThisItem.Status.Value
✓ Extracts string: "High"

Trainer Speaking Script & Pedagogical Cues:

Part 6 • Debugging & Reality Check

5 Dangerous Misconceptions vs. Cloud Reality

Avoid these 5 common beginner traps before they cause design confusion or broken formulas.

Misconception 1: "I have to write code for every row in the table."

Reality: False! You write code ONCE in the Template Cell. Power Apps repeats it for 1, 10, or 10,000 rows automatically.

Misconception 2: "Editing Row 3 changes only Row 3's design."

Reality: False! You cannot edit Row 3 directly. Any layout or color change made in the Template Cell applies to all rows.

Misconception 3: "A Gallery copies records into tablet storage."

Reality: False! The gallery is only a viewfinder (lens) displaying records fetched from the SharePoint cloud via the connector.

Misconception 4: "Writing Table.Title works inside the gallery."

Reality: Referencing the table name returns a column array. Inside a row, you MUST use ThisItem.Title to specify the current row.

Misconception 5: "ThisItem.Priority shows text on screen."

Reality: Priority is a Choice column! It returns a record object. You must write ThisItem.Priority.Value to extract the string.

Trainer Speaking Script & Pedagogical Cues:
