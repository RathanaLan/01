SketchUp (.SKP) File Conversion Guide

Trimble SketchUp (.skp) is a proprietary binary CAD format. To bring your SketchUp model directly into this 3D Web Studio with full materials, textures, and animations:

1
In SketchUp: Click File ➔ Export ➔ 3D Model...
2
Select Format: Choose glTF / GLB, OBJ (.obj), or AutoCAD DWG/DXF (or 2D Section as PDF / PNG).
3
Drop it here: Drag and drop the exported .glb, .obj, .dxf, or .pdf right into this window!

💡 Tip: You can also drag any existing .obj, .gltf, or .pdf right now!
