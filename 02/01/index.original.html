DENSO MMS STANDARD PROCEDURE FY2025 RELEASE

Manufacturing Structure Strengthening Self-Check Diagnosis for DENSO Group Companies

This procedure defines mandatory self-check diagnosis audits for production line stability, Furikae operator rotation competency, and Kakotora recurrence prevention across global plants.

1. Diagnosis Procedure (Plan-Do-Check-Action)

  1. Daily Genba 5-minute pre-shift confirmation.
  2. Weekly line cycle variance and scrap root cause audit.
  3. Monthly cross-plant Kakotora bench testing.
  4. Semi-annual management capability review.

2. Key Assessment Pillars

  • Standard Work: 100% adherence to SOS/JES sheets.
  • Equipment Health: TPM autonomous maintenance level 4.
  • Quality Assurance: Zero outflow through Poka-Yoke interlocks.
  • Human Development: Skill-map multi-skilling index > 85%.
